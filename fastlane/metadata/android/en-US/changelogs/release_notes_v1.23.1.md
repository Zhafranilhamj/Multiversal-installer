### 📱 Phone (App)
• **Security Scan works again.** Tapping it used to do nothing at all — no spinner, no message. It now starts a scan and shows you every step.
• **Scanning an installed app** from Manage now shows the result inside the app. Before, it quietly opened a web page and told you nothing.
• **Bigger files can be scanned.** The limit goes from 32 MB to 650 MB, so large games and bundles are no longer refused.
• **Large uploads** show real progress and no longer give up part-way through.
• **A scan that cannot run now says why** — scanner switched off, missing key, or no connection — instead of failing silently.
• Hashes are now formatted the same way everywhere, which fixes lookups on devices set to Arabic, Hindi and other non-Latin locales.

### 📺 Android TV
• **Bigger files can be scanned:** the limit is now 650 MB instead of 32 MB.
• **A failed scan no longer looks clean.** When the scanner could not be reached, the file was reported as safe; it now reports the error.
• Large uploads no longer time out part-way and show real progress.

### ⌚ Wear OS
• Picks up the updated shared scanning code used by the phone and TV builds.
• A failed scan no longer looks clean — when the scanner could not be reached, the file was reported as safe.
